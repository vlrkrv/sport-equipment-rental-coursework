# Курсова робота з об'єктно-орієнтованого програмування 

 ## Sport Equipment Rental — Система оренди спортивного інвентарю

**Студентка:** Валерія Кравченко  
**Мова:** Java  
**Дата:** 2026

---

## Опис проєкту

Консольний/графічний застосунок для управління орендою спортивного
інвентарю. Реалізовано з використанням принципів ООП:

- **Інкапсуляція** — приватні поля класів з геттерами/сеттерами
- **Наслідування** — базові та похідні класи (наприклад, `Equipment` → `Bike`, `Ski`)
- **Поліморфізм** — перевизначення методів `toString()`, `getInfo()`
- **Абстракція** — абстрактні класи та інтерфейси
- **Композиція** — класи-менеджери, що містять колекції об'єктів

## Функціональність

- додавання спортивного інвентарю (велосипеди, лижі, ковзани тощо);
- реєстрація клієнтів;
- оформлення оренди на певний термін;
- повернення інвентарю;
- розрахунок вартості оренди;
- перегляд списку доступного та орендованого інвентарю;
- пошук і фільтрація;
- збереження/читання даних (файл або БД).
